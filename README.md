E-Commerce Web Application
A responsive, full-stack-style e-commerce frontend built with the Next.js App Router. Users can browse a product catalog, search and filter items, add products to a cart, and complete purchases using a simulated wallet balance.

Key features
* 🛍️ Product catalog with search, category filtering, and multi-field sorting (price, rating, discount, stock)
* 📄 Dynamic product detail pages with image gallery, specs, and reviews
* 🛒 Persistent shopping cart (saved to localStorage, survives refresh)
* 💳 Checkout flow with wallet-balance payment and order confirmation
* 🔐 User authentication (register / login) and purchase history
* 🌗 Light/dark mode and fully responsive design
  
Tech stack
* Framework: Next.js 15 (App Router), React 18
* Language: TypeScript (strict mode)
* Styling: Tailwind CSS + shadcn/ui (Radix UI components)
* State management: React Context API
* Data: DummyJSON REST API via Axios
* Deployment: Vercel
